# Car Finder Component

Ik wil een een kenteken checker maken voor een auto bedrijf website. die moet alleen een component worden zodat ik deze later kan gebruik in een website. 

Je zoekt je kenteken op en via de RDW api haalt hij de gegevens van je auto op. Vervolgens zie je die gegevens in stap 2 en kun je via het formulier keuzes maken over waarvoor je contact wil opnemen. 

In de screenshots zie je een voorbeeld van hoe het moet worden.
